# 常见问题

本文介绍 JMC 平台接入、短信发送和号码使用中的常见问题。各国家和地区的发信要求、资费及办理时间可能不同，具体请以服务团队确认的信息为准。

## 1. 账户与计费

### 1.1 JMC 使用什么币种计费？

**答：** JMC 使用美元计费。具体币种和费用请以账户信息及服务团队提供的报价为准。

### 1.2 如何支付费用？

**答：** JMC 采用预充值方式。您可以联系锦木通信服务团队办理充值，并在平台查询账户余额。

### 1.3 新客户如何接入？

**答：** 请联系锦木通信服务团队，提供业务需求、目标国家或地区等信息，并按要求填写申请资料。服务团队会协助您开通账号、确认发信配置和办理充值。

### 1.4 账号开通需要多长时间？

**答：** 开通时间取决于申请资料、目标国家或地区的要求及审核进度。请在提交需求时向服务团队确认预计办理时间。

### 1.5 首次登录时如何获取密码？

**答：** 账号创建后，登录地址和初始密码会发送至账号邮箱。请按邮件提示登录并修改密码；如未收到邮件，请检查垃圾邮件或联系服务团队。

### 1.6 一个账号可以使用多个邮箱或号码登录吗？

**答：** 一个 JMC 账号使用一个邮箱登录。有关手机号登录和绑定方式，请联系服务团队确认您的账号配置。

### 1.7 一个主体有多个业务，如何管理？

**答：** 可以根据业务需求使用不同的 Sender ID、Key 或账号进行管理。各方式的权限、查询和计费安排可能不同，请联系服务团队确认适合您的配置。

### 1.8 忘记密码或无法登录怎么办？

**答：** 请先检查账号、密码和手机号区号。仍无法登录时，可使用登录页面的“忘记密码”重置密码，或联系锦木通信服务团队。详情请参考 [平台使用手册](platform-usage.md)。

## 2. 发信号码与 Sender ID

### 2.1 如何购买发信号码？

**答：** 请向服务团队提供目标国家或地区、号码用途、预计使用时长及需要发送的短信类型。服务团队会协助确认可用号码、申请材料、费用和办理时间。

不同国家和地区的号码供应及使用条件可能不同，详情可参考：

- [Vonage 号码可用国家和地区](https://api.support.vonage.com/hc/en-us/articles/204015043-Which-countries-does-Vonage-have-numbers-in)
- [短信号码](https://api.support.vonage.com/hc/en-us/articles/115011451687)
- [短信和语音号码](https://api.support.vonage.com/hc/en-us/articles/115011612267)
- [语音号码](https://api.support.vonage.com/hc/en-us/articles/115011761808)

### 2.2 申请 Sender ID 会影响价格吗？

**答：** 可能会。费用取决于目标国家或地区、所选通道及 Sender ID 的注册要求。申请前请向服务团队确认适用资费。

## 3. 不同国家和地区的发信

### 3.1 巴基斯坦的 Sender ID 有什么要求？

**答：** 不同运营商对 Sender ID 的要求可能不同。请在申请前将拟使用的 Sender ID 和发信内容提供给服务团队，确认格式和注册要求。

### 3.2 向台湾地区发送短信有什么要求？

**答：** 可能需要提供短信模板进行通道报备；如果短信包含链接，也请向服务团队确认链接的报备要求。请在发送前提供目标用途、短信内容及相关资料。

### 3.3 在澳大利亚发送短信需要准备什么？

**答：** 请向服务团队说明短信用途、目标号码、发信人及所需号码数量。团队会根据您的业务场景确认是否需要购买号码或申请 Sender ID，以及对应的材料、费用和办理时间。

### 3.4 在美国或加拿大发送短信有哪些要求？

**答：** 发信前请与服务团队确认适合的号码类型、注册要求和可用通道。不同号码类型的申请材料、发送速度、费用和审核时间可能不同。

有关美国和加拿大免费电话号码的注册说明，可参考 [Vonage TFN 说明](https://api.support.vonage.com/hc/en-us/articles/360055483251-Verified-Toll-Free-Numbers-TFN-US-and-Canada)。

### 3.5 美国和加拿大有哪些发信号码类型？

**答：** 常见类型包括长号码、短代码和免费电话号码（TFN）。适用场景、注册要求、发送速度及费用因号码类型和业务配置而异，请联系服务团队确认。

### 3.6 TFN 号码的短信发送速度是多少？

**答：** 发送速度取决于账户配置、目标地区及通道限制。请在开通或发送前向服务团队确认适用于您账户的速度。

### 3.7 如何申请俄罗斯的 Sender ID？

**答：** 请联系服务团队确认申请材料、注册要求、费用和办理时间。实际要求和资费以申请时确认的信息为准。

### 3.8 韩国短信发送和退订有哪些注意事项？

**答：** 短信编码和退订要求可能因业务内容及通道而异。发送前请向服务团队确认适用规则，并使用测试号码验证显示效果。可参考 [Vonage 韩国发信规则](https://api.support.vonage.com/hc/en-us/articles/204017213-South-Korea)。

## 4. 号码管理与接口

### 4.1 如何迁移号码？

**答：** 如需在账号或 Key 之间迁移号码，请联系服务团队，说明当前账号、目标账号和需要迁移的号码。团队会协助确认迁移条件、所需资料和迁移后的配置。

### 4.2 子 Key 可以使用主账号的号码吗？

**答：** 是否可以共享取决于账户配置和号码的使用权限。请联系服务团队确认您的业务是否支持以及如何申请。

### 4.3 如何停用某个 Key 的短信或语音功能？

**答：** 请联系服务团队，说明需要停用的 Key 和功能。团队会协助确认适用的停用方式及影响。

### 4.4 发信接口如何保障安全？

**答：** 发信接口使用 Key 和密钥进行身份认证。请妥善保管凭据，并按账户支持的配置设置 IP 白名单；具体配置方式请联系服务团队。接口调用示例可参考 [API 接入手册](api.md)。

## 5. 号码校验与语音

### 5.1 如何校验号码状态或归属地？

**答：** 号码状态、归属地和相关查询能力因服务版本、目标国家或地区及数据覆盖范围而异。如有需求，请联系服务团队确认可用功能、费用和接入方式。有关上游服务的介绍，可参考 [Identity Insights API文档](https://developer.vonage.com/en/api/identity-insights?source=identity-insights)。

### 5.2 如何接入语音 API 或配置 SIP？

**答：** 如需使用语音 API 或 SIP，请联系服务团队确认账户权限、所需号码、接入方式及配置参数。可参考 [Vonage Voice API 文档](https://developer.vonage.com/en/voice/voice-api/code-snippets/making-calls/make-an-outbound-call-with-ncco?source=voice)了解语音调用示例。使用密钥时，请妥善保管凭据。

### 5.3 语音并发如何收费？

**答：** 费用取决于目标国家或地区、业务用量及账户配置，请联系服务团队获取适用报价。

### 5.4 号码是否支持企业认证或显示名称？

**答：** 号码的使用权、企业认证和显示名称支持情况，可能因号码类型、目标地区及业务场景而异。请联系服务团队确认适用条件和所需材料。

## 6. 短信发送与问题排查

### 6.1 发送成功后，为什么收件人没有收到短信？

**答：** 平台或接口返回成功，不代表短信已经送达手机。请检查收信号码和发送记录，并通过已确认的回执机制或测试号码核实投递情况；如仍有问题，请联系服务团队。

### 6.2 为什么一条短信会按多段计费？

**答：** 短信内容超过单条容量时，会拆分成多段发送并按段计费。可用容量受短信编码和内容影响，签名、空格及特殊字符也需要计入。可以使用 [API 接入手册](api.md)中的短信长度与分段计算工具估算；实际段数和费用以平台记录为准。

### 6.3 短信出现乱码或问号怎么办？

**答：** 请检查完整短信内容和编码类型。包含中文或 GSM 字符集外字符时，应使用 `unicode`；通过 API 发送时，还应检查请求编码。建议先向测试号码发送，确认显示效果。详情请参考 [API 接入手册](api.md)。

### 6.4 上传收信号码失败或提示异常怎么办？

**答：** 请使用平台提供的标准模板，填写包含国家或地区区号的收信号码，并查看上传后的检测结果。如提示存在异常数据，可下载异常数据文件，修改后重新上传。详情请参考 [平台使用手册](platform-usage.md)。

### 6.5 为什么部分号码没有发送？

**答：** 请先检查号码格式及上传后的检测结果，并查看对应 Key 下是否配置了手机号或国家黑名单。具体发送情况请以平台记录为准；如仍有疑问，请联系服务团队。

### 6.6 如何查看短信发送记录？

**答：** 在平台进入 **日志管理 → 日志查询**，可以按号码、Message ID、时间等条件查询发信记录。通过网页创建的任务还可以在 **任务管理 → 任务统计** 中查看；API 发信不提供任务统计，应通过日志查询。详情请参考 [平台使用手册](platform-usage.md)。

### 6.7 定时发送的任务可以修改吗？

**答：** 定时任务在实际发送前，可以先暂停任务再修改。任务开始发送后无法停止，请在提交前核对号码、短信内容和发送时间。详情请参考 [平台使用手册](platform-usage.md)。

### 6.8 API 请求超时后可以直接重试吗？

**答：** 请求超时后，发送结果可能不明确。请先核查发信日志或已确认的回执记录，再决定是否重试，避免重复发送。如无法确认结果，请联系服务团队。

# 平台操作视频教程

本教程通过视频介绍短信发送、日志下载和黑名单配置，帮助您快速熟悉平台的常用操作。

## 短信发送

观看视频，了解如何创建发信任务并完成短信发送。

<video controls width="100%">
  <source src="../../videos/platform-quick-start.mp4" type="video/mp4">
  您的浏览器不支持播放此视频。
</video>

主要操作步骤：

1. 创建发信任务，填写任务名称。
2. 配置发信号码（From）和短信内容。
3. 选择短信编码类型。
4. 上传收信号码文件。
5. 选择立即发送或定时发送。
6. 查看发信日志。

发送前，请确认发信号码、短信内容和收信号码无误。

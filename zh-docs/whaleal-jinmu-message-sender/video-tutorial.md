## 操作流程

视频主要介绍以下内容：

1. 创建发信任务并填写任务名称。
2. 配置发信号码（From）及短信内容。
3. 选择短信编码类型。
4. 上传收信号码文件。
5. 选择立即发送或定时发送。
6. 查看发信日志。

请根据实际业务需求完成配置，并在发送前确认发信号码、短信内容及收信号码信息正确。

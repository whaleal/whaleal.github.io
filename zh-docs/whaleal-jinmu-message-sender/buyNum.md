# 号码购买

**购买号码请统一联系锦木通信服务团队办理。** 服务团队会根据您的用途，确认可用号码、申请材料、费用和办理时间。

## 1. 选择号码

先确定希望号码归属哪个国家或地区，再说明要向哪里发短信，或接收来自哪里的短信。号码支持的功能和覆盖范围会随国家、运营商和号码类型而异。

| 使用场景 | 申请时请确认 |
| :--- | :--- |
| 发送验证码、通知或营销短信 | 是否支持向目标地区发送这类短信，发信前是否需要注册或验证 |
| 接收短信或用户回复 | 是否能接收目标地区用户发来的短信，以及如何接收入站通知 |
| 双向短信 | 同一个号码能否在目标地区发送和接收短信 |
| 短信与语音 | 号码是否同时支持所需的短信功能和语音功能 |

## 2. 提交申请

1. **提供需求。** 告知服务团队所需的号码归属地、号码数量、预计使用时长和用途。用于短信时，可一并提供目标地区和短信样例。
2. **确认方案。** 由服务团队确认可用号码类型、功能、费用、预计办理时间，以及是否需要注册或验证。
3. **按要求提交材料。** 所需材料因国家和号码类型而异，例如公司资料、地址证明或用途说明。请按服务团队确认的清单准备。

## 3. 开通与测试

服务团队确认号码开通及所需的注册或验证完成后，按确认的发信配置进行测试。使用该号码作为发件人时，按要求填写 `From`。首次发信可参考[平台发信快速开始](quick-start-platform.md)或[API 发信快速开始](quick-start-api.md)。

如需接收短信，请先和服务团队确认号码支持入站短信，并联系团队配置 Webhook。发信目的地的 Sender ID 注册要求和材料请查看[国家及地区规则](sender-id.md)。
